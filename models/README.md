# Models

- `shipped_recyclenet_small/` - the model shipped in app version 0.4.1 (RecycleNet-small, MIT licence).
- `classifier-package-v4/` - reproduction scripts, data manifests, audits and credits for the v4 candidate classifier. The v4 candidate weights (`model/dooreha_candidate_v4_final.onnx`) and the v1-v3 candidate weights are NOT included: the candidate backbone licence is unresolved, so they are not redistributed here and must not be used commercially until that is cleared. See `classifier-package-v4/credits/` for the attribution manifests and licence texts that do exist.
